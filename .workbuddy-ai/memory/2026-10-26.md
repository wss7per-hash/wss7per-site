# 2026-10-26

## 个人网站搭建

在 `F:/vibe coding/个人网站` 从零搭了一个 Astro 7 个人网站，含网页后台。

**技术栈**：Astro 7.4.2（静态输出）+ Decap CMS 3.17.1 + Netlify 托管（规划中）

**关键决策**
- 用户要"免费 + 好记域名 + 网页后台"，结论：托管免费，域名需花钱（约 ¥70/年）。先走免费子域名。
- 后台选 Decap CMS + Netlify Identity + Git Gateway，后台在自家域名 `/admin`，不依赖第三方 SaaS。
- 内容用 Markdown（`src/content/posts/*.md`），Decap 通过 `permalink` 字段控制 URL（避免中文标题生成的 slug 为空）。

**结构**
- `src/site.config.ts` —— 站名、简介、关于、社交链接，改一处全站生效
- `src/styles/global.css` —— 配色变量在 `:root`
- `src/layouts/Base.astro` —— 导航在此
- `src/pages/` —— index / about / blog/index / blog/[...slug]
- `public/admin/` —— 后台入口与 config.yml

**踩坑**
- Astro 7 要求 Node >= 22.23.4，本机 PATH 里是 22.22.2，必须切到 `C:\Program Files\nodejs`（v24.16.0）才能构建。`netlify.toml` 已固定 NODE_VERSION=24。
- 正文里的 Markdown 表格需单独写 `.prose table` 样式，否则挤成一团。
- Astro dev 模式下 `/admin/` 返回 404，需用 `/admin/index.html`；生产构建后 `/admin/` 正常。

**验证**：6 个页面构建通过，首页/列表/文章/关于均已截图核对。
